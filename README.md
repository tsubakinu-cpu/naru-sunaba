# 鳴る砂場

描いた粒が、音楽になる。CanvasとWeb Audio APIで作った、小さな音の実験室です。

`index.html` ひとつで動きます。外部ライブラリ、画像、音声サンプル、ビルド、サーバー側の処理は使いません。ダウンロードしたHTMLをブラウザで開くか、GitHub Pagesなどの静的ホスティングに配置してください。

## 遊び方

下のパレットで粒を選び、砂場をドラッグすると描けます。最初のタップで音が有効になります。砂は落ち、水と油は流れ、火は燃え広がり、種は水に触れると育ちます。鈴の石を足場にして、上から粒を落としてみてください。

砂、水、油、火、煙、氷、雪、石、金属、種、鈴の石、ガラス、植物、溶岩の14種類。加熱・冷却ブラシでも温度を変えられます。32種類の反応を発見すると図鑑に記録されます。

音は8分音符のタイミングにそろえ、長調／短調ペンタトニック、ドリア、和音階の音を使います。初期BPMは96。BPMは40〜180で変更でき、同時発音は16音、8分音符ごとに最大6音、1拍で最大10音です。反応、鈴、発芽の音を優先し、同じ音の重なりを間引きます。

スマホの音楽・録画設定は右下のBPMボタンから開きます。PCでは下部に表示されます。Spaceで一時停止、Eで消しゴム。砂場にキーボードフォーカスがあるときは、矢印キーで位置を移動し、Enterで粒を置けます。

## 共有と動画

「この砂場を共有」は、グリッド、温度、成長状態、乱数状態、BPM、スケールを圧縮してURLのハッシュに保存します。サーバーに世界のデータを送信しません。リンクを開くと保存した状態から再生します。大きな砂場をスマホで開く場合もセルを3 CSS px以上に保ち、移動ツールでスクロールできます。ローカルファイルのリンクは他の端末で開けないため、共有には公開URLを利用してください。

「15秒録画」は砂場のCanvasと合成音をMediaRecorderで記録します。WebM、または対応している場合はMP4で保存できます。録画後のプレビューから「動画を保存」を押してください。タブを隠すとシミュレーションと音を停止し、途中の録画は中止します。録画にはマイクやカメラの許可は不要です。

## 日替わりの実験

端末のローカル日付をシードにしてお題を選びます。同じ日付では同じお題になります。「鈴を8拍以内に3回」「火を使わずガラス」「種から8節の成長」「水から5粒の氷」の4種類です。図鑑とお題の達成状況は、このブラウザのlocalStorageに保存します。プライベートブラウジングや保存領域の削除後は記録が残らない場合があります。

## 実装と対応範囲

シミュレーションは固定30ステップ/秒、描画はrequestAnimationFrameです。16×16セルの更新領域と休止処理で、止まった粒の計算を省きます。共有の標準圧縮はCompressionStreamのdeflate、作成時に非対応の環境ではLZWを使います。deflate形式の共有リンクを読むにはDecompressionStream対応ブラウザが必要です。

録画形式とWeb Audioの動作はブラウザ依存です。検証結果は `verification.md` を参照してください。スマホサイズのPlaywright検証はタッチ操作をエミュレーションしたもので、実機Safariの検証ではありません。

## GitHub Pages

このリポジトリの `index.html` をルートに置き、Settings → Pages で `Deploy from a branch`、`main`、`/ (root)` を選ぶと公開できます。ビルドコマンドは不要です。
